# A migration that has run somewhere is HISTORY. Editing it does not change any
# database that already applied it; it only makes Flyway refuse to start against
# that database, with a checksum mismatch and nothing that says which edit did
# it. That is not hypothetical - V016 was edited to translate one comment from
# French to English, and the API could not start on a developer machine for
# hours afterwards while the process that was already up served a half-stale
# classpath.
#
# CI never caught it because CI starts from an empty database, where a rewritten
# migration is simply the only version there has ever been. Only a database that
# predates the edit can tell, and CI does not have one. This file is that
# database's memory, kept in the repository.
#
# Adding a migration: add its line here in the same commit. Print the value with
#   mvn -pl app test -Dtest=MigrationChecksumTest
# which names the missing file and the checksum it computed.
#
